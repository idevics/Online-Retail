# Online Retail Customer Analysis

## Overview
This project uses the Online Retail dataset to analyze customer purchasing behavior, predict future customer spending, and classify customers into spending segments using machine learning.

## Dataset
The project uses the Online Retail dataset, which contains transaction records, product information, customer IDs, quantities, prices, invoice dates, and countries.

## Project Workflow
- Data exploration and quality assessment
- Data cleaning and preprocessing
- Feature engineering and customer-level aggregation
- Customer spending segmentation
- Classification and regression model comparison
- Hyperparameter tuning
- Feature coefficient analysis and error analysis

## Models
**Classification**
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

**Regression**
- Linear Regression
- Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- K-Nearest Neighbors Regressor
- Kernel Ridge Regression

## Evaluation
Classification models are evaluated using Accuracy, Macro-F1, and Weighted-F1.

Regression models are evaluated using MAE, RMSE, and R².

A baseline model is used for each task to provide a reference for model performance.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Key Objectives
- Understand customer purchasing patterns.
- Predict future customer spending based on historical behavior.
- Group customers into low, medium, and high spending segments.
- Compare machine learning models and analyze their performance.
